## 🚀 製作流程（按順序做）

### Step 0: 環境準備（10 分鐘）

1. 開啟 PowerPoint，新建空白簡報
2. **設計 → 投影片大小 → 自訂大小**：寬 60 cm、高 85 cm、方向**直向**
3. **檢視 → 尺規 / 格線 / 輔助線**全部打開
4. 安裝中文字型 **思源黑體**（免費，Google 搜「Noto Sans CJK TC」）
5. 安裝英文字型 **Inter**（免費，https://rsms.me/inter/）

---

### Step 1: 拉出 10 個區塊空框（30 分鐘）

打開 `00_layout.md`，照「A1 直式 v2 結構」圖示拉出 10 個矩形框，**先別填內容**，只標號 ①~⑩。

關鍵尺寸（cm）：

| 區塊 | 位置 | 寬 × 高 |
|---|---|---|
| ① 標題列 | 頂部全寬 | 60 × 8 |
| ② Hero Visual | 標題下全寬 | 60 × 14 |
| ③ 摘要+動機 | 左中上 | 30 × 17 |
| ④ 系統架構 | 右中上 | 30 × 17 |
| ⑤ 漏斗圖 | 左中 | 28 × 12 |
| ⑥ 方法對比表 | 右中 | 28 × 12 |
| ⑦ 實驗結果 | 中下全寬 | 60 × 18 |
| ⑧ 結論 | 左下 | 30 × 8 |
| ⑨ 未來展望 | 右下 | 30 × 8 |

**檢查點**：縮到 20% 比例看，整體應該像分成 3 欄 × 5 列的網格。

### Step 2: 填入文字內容（2-3 小時）

每個區塊對應一個 markdown 檔，直接複製文字進 PPT：

| 區塊 | 用哪個 md 檔 |
|---|---|
| ① 標題列 | `01_title.md`（**選一個 Tagline**，建議第一個） |
| ② Hero Visual | `02_hero_visual.md`（這個 Step 5 才做） |
| ③ 摘要 | `02_abstract.md` + `03_motivation.md` |
| ④ 系統架構 | `04_architecture.md` |
| ⑤ 漏斗圖 | `05b_repair_funnel.md`（圖 + 副標） |
| ⑥ 方法對比表 | `05c_method_comparison.md` |
| ⑦ 實驗結果 | `05_results.md` |
| ⑧ 結論 | `06_conclusion.md` |
| ⑨ 未來展望 | `07_future_work.md` |
| ⑩ 致謝+QR | `08_qr_acknowledgement.md` |

**字級**全部照各 md 檔內標示，**不要自己改大改小**。
**配色**：
- 主色（標題、小標）：`#1f3a5f` 深藍
- 強調（區塊大標）：`#2e6fb8` 鮮藍
- 重點數字（+172%, 81.7%, 100%）：`#d95f4a` 橘紅

### Step 5: 製作 Hero Visual（3-4 小時）⭐ 最重要

> 這是整張海報的靈魂，70% 的得獎機率在這。**請投入最多時間**。

打開 `02_hero_visual.md`，照 5 步驟做：

#### 5.1 選 4 題對比題目（30 分鐘）
從 `paper/dept_report/run_data/run3_60_merged.csv` 撈：
- 篩選條件：本系統 Status=PASS，且該題在 baseline run 為失敗
- 挑視覺差異最大的 4 題
- 涵蓋國小/國中/高中（建議：國小 1 題、國中 1 題、高中 2 題）

#### 5.2 找對應影片（30 分鐘）
- **本系統成功影片**：`runs/` 三次 run 之一，找到該題的最終 `.mp4`
- **Baseline 失敗影片**：`runs/20260516_170408/` 目錄底下找
  ```bash
  find runs/20260516_170408 -name "*.mp4" | head
  ```

#### 5.3 抽 frame（30 分鐘）
裝 ffmpeg：`brew install ffmpeg`

```bash
# 抽影片中段最關鍵的一格
ffmpeg -i 影片.mp4 -ss 00:00:30 -vframes 1 -q:v 2 截圖.png

# 或抽 2×2 網格
ffmpeg -i 影片.mp4 -vf "select='not(mod(n\,60))',tile=2x2:padding=8" \
       -frames:v 1 grid.png
```

**選 frame 訣竅**：
- Baseline 失敗：選**最爛瞬間**（重疊、出格、亂碼那一格）
- 本系統成功：選**最帥瞬間**（公式+圖形完整、分段清晰那一格）

#### 5.4 標註（1-2 小時）
用 PPT 或 Figma：
- **左半 4 張 Baseline**：紅框 3pt + 紅字標籤
  - 標籤例：「物件重疊」「文字超出畫面」「公式錯誤」「API 幻覺」
- **右半 4 張本系統**：綠框 3pt + 綠字標籤
  - 標籤例：「分段清晰」「同步旁白」「數學正確」「佈局平衡」
- **中央放 `+172%` 140pt 橘紅巨字**
- **下方** 22pt 灰色 caption：
  > 同一題、同一模型（Claude Opus），唯一差別在「分段教學設計」與「三層自我修復」迴圈

#### 5.5 整體調整
- 紅框 frame 加灰調濾鏡（降飽和度 30%）讓 baseline 看起來「灰暗無力」
- 綠框 frame 保持原色飽滿
- 視覺感是：左暗右亮、中央爆炸數字

### Step 6: QR Code（先放佔位，URL 之後補）

📌 **三個 URL 廖振廷會之後給你**（包含 Demo 影片、GitHub repo、AIED 論文），**不用問他要**。

**你現在要做**：
1. 在海報右下 QR 區放 **3 個灰色佔位方框**（每個 5×5 cm）
2. 框內放白色大問號 `?` 或文字「QR Pending」
3. 下方加 18pt 標籤：**Demo** / **Code** / **Paper**
4. 並排排列，每個間隔約 1cm

**等廖振廷給 URL 後**（這步你之後再做，5 分鐘搞定）：
```bash
brew install qrencode

qrencode -o qr_demo.png   -s 12 "<demo URL>"
qrencode -o qr_github.png -s 12 "<github URL>"
qrencode -o qr_paper.png  -s 12 "<paper URL>"
```

或線上工具：https://www.qr-code-generator.com/

把生成的 3 個 PNG 直接替換佔位方框即可，**排版不會跑掉**。

### Step 7: 校對檢查清單（30 分鐘）

⚠️ **作者名字校對**（最容易出錯）：
- ✅ 廖振廷
- ✅ 劉澤文
- ✅ **周庭伊**（不是「周廷翊」，書面報告誌謝段有 typo）
- ✅ **巫冠儀**（不是「吳冠頤」）
- ✅ **賴以威** 副教授（不是「賴怡瑋」）

⚠️ **AIED badge** 必須出現至少一次（標題列右上 + 結論段最後一行二擇一）

⚠️ **數字校對**（從 `paper/dept_report/analysis/stats_summary.txt` 撈的真實數字）：
- 本系統 PASS：**49/60 = 81.7%**
- Baseline PASS：**18/60 = 30.0%**
- 提升：**+172%**
- Fisher p：**1.62×10⁻⁸**
- Cohen's d：**1.03**
- Render 成功率：**60/60 = 100%** vs **40/60 = 66.7%**
- 平均時間：**113 秒/題**
- 平均成本：**$0.35/題**
- 高中段提升：**+63.3pp**（5% → 68.3%）

⚠️ **不要出現的東西**：
- ❌「賴怡瑋」「周廷翊」「吳冠頤」
- ❌「3 小時手刻 Manim」之類沒有出處的數字
- ❌ 任何中英夾雜怪句（檢查每段文字流暢度）

---

### Step 8: 整體視覺平衡（1 小時）

縮到 20% 比例看整張海報：
- [ ] **5 公尺視覺**：`+172%` 一定要能 5 秒看到
- [ ] **顏色節奏**：橘紅數字不超過 5 處（過多會雜亂）
- [ ] **留白足夠**：每個區塊四周至少 1cm 留白
- [ ] **對齊整齊**：所有區塊邊緣對齊到 PPT 輔助線
- [ ] **沒有跑版**：縮 100% 比例檢查圖片有沒有壓字
- [ ] **沒有破圖**：所有圖片放大到 150% 看仍清晰

---

### Step 9: 輸出（10 分鐘）

1. **PPT 存檔**：`LLManim_Poster_v2_YYYYMMDD.pptx`
2. **PDF 輸出**：`檔案 → 匯出 → PDF`，選**高品質列印**
3. **PNG 預覽**（給組員 review 用）：
   ```bash
   # macOS Preview 即可，或用 ImageMagick
   convert -density 300 海報.pdf 海報_preview.png
   ```

## 📞 跟廖振廷的溝通分工

| 找廖振廷 | 不用找廖振廷（自己決定即可） |
|---|---|
| 3 個 QR 的 URL（他之後會給） | 字級、配色、排版細節（照各 md 規範） |
