# 00 — 整體排版示意（v2 — 競賽強化版）

## 設計哲學

海報不是「論文壓縮版」，是**訊息漏斗**：
- **5 公尺**：一張圖 + 一個數字
- **1 公尺**：故事線（為什麼→怎麼做→成果）
- **駐足**：細節 + QR 行動

⚠️ v2 重大變更：**移除原本「摘要 + 研究動機」二欄頂部**，改為 **Hero Visual + Tagline** 第一視覺。摘要併入 Hero 下方，研究動機改放系統架構之前作為「為什麼」鋪陳。

## 視覺優先級（評審 5 秒看到什麼）

1. **Hero +172%** 巨字 → 5 秒抓到「我們做出比 baseline 強 2.7 倍的東西」
2. **Hero 影片網格** → 知道你做的是「教學動畫」具體長怎樣
3. **AIED Badge** → 國際背書，可信度
4. **Tagline** → 一句話記憶點
5. **三層漏斗圖** → 知道你的核心技術
6. **figure5 分學階柱狀** → 數據說服力
