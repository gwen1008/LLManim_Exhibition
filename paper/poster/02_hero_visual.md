## 製作步驟（給組員或你自己做）

### Step 1：選 4 題對比題目
從 60 題 benchmark 中挑「baseline 失敗、本系統成功」的對比題。
建議從這四題擇：（從 `paper/dept_report/run_data/run3_60_merged.csv` 撈，挑 Status=PASS 且 Knowledge Point 視覺明顯的）

**挑選原則**：
- 視覺差異要明顯（一看就知道誰好誰壞）
- 涵蓋不同學階（國小／國中／高中各 1）
- 第 4 題用最炫的（例如三角函數或幾何圖形）

### Step 2：抽 frame 截圖
- Baseline 失敗 frame：選 **「最爛瞬間」**（物件重疊、文字爆出、公式錯誤）
- 本系統成功 frame：選 **「教學最關鍵那一格」**（分段中段，有公式 + 圖形）

**抽 frame 命令範例**（ffmpeg）：
```bash
# 從中段抽 frame（影片 50% 處）
ffmpeg -i baseline_failure.mp4 -ss 00:00:30 -vframes 1 -q:v 2 baseline_Q1_fail.png
ffmpeg -i llmanim_success.mp4 -ss 00:00:30 -vframes 1 -q:v 2 llmanim_Q1_success.png
```

**或抽多 frame 合成網格**：
```bash
ffmpeg -i video.mp4 -vf "select='not(mod(n\,30))',tile=2x2:padding=8:color=red" \
       -frames:v 1 grid.png
```

### Step 3：標註
用 PPT、Figma 或 Photoshop：
- 失敗 frame 加 **紅框 + 紅字標籤**（「物件重疊」「文字超出」「公式錯誤」）
- 成功 frame 加 **綠框 + 綠字標籤**（「分段清晰」「同步旁白」「數學正確」）

### Step 4：中央放 +172% 巨字
- 字體：思源黑體 Heavy
- 字級：140pt
- 顏色：`#d95f4a` 橘紅
- 下方加 `81.7%  vs  30.0%`（48pt 對比）

### Step 5：caption
位置：Hero 底部，置中，22pt 灰色：
> 同一題、同一模型（Claude Opus），唯一差別在「分段教學設計」與「三層自我修復」迴圈

## ⚠️ 重點提醒

這張 Hero Visual 做得好不好，**決定海報 70% 的得獎機率**。請投入最多時間在：
1. **選題**（4 題對比要有故事性）
2. **frame 截圖時機**（baseline 要選最慘、本系統要選最帥）
3. **標註精準**（紅字要點出具體缺陷，不是「品質差」這種空話）

如果只能投入有限時間做這份海報，**所有時間給 Hero Visual**。其他區塊都是輔助。
