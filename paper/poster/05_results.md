## ▍ 三次獨立實驗（如圖區放不下，可放底部文字）

| Run | 本系統 | Baseline |
|---|---:|---:|
| Run 1 | 41/60 = **68.3%** (FJW μ=4.42) | — |
| Run 2 | 51/60 = **85.0%** (FJW μ=4.57) | — |
| Run 3 | 46/60 = **76.7%** (FJW μ=4.39) | — |
| **Majority ≥ 2/3** | **49/60 = 81.7%** | **18/60 = 30.0%** |
| 三 run 全 PASS | 37/60 (61.7%) | — |
| 三 run 任一 PASS | 52/60 (86.7%) | — |
| Render 成功率 | **60/60 (100%)** | 40/60 (66.7%) |

> Render 成功率對比：Fisher exact p = 2.85 × 10⁻⁷

## ▍ 關鍵洞察（底部文字區）

失敗案例分析顯示，**本系統 Render 成功率達 100%**（60/60，baseline 僅 66.7%），證明三層自修復迴圈有效消除執行期錯誤。剩餘失敗主要集中於 **「程式碼 Critical」**（22 例）與 **「概念對齊過低」**（8 例），而非視覺呈現問題（僅 1 例），顯示動畫品質瓶頸**不在「視覺呈現」而在「概念對齊」**，為後續教育型 AI 研究指出明確方向。
