# Geometry Examples

這個資料夾包含 geometry 相關的 Manim 範例代碼。

## 檔案列表


## MovingAround
**說明**: 綜合練習物件的平移（shift）、顏色填充（set_fill）與縮放（scale）等基礎動畫操作。


## GrowingSquare
**說明**: 展示物件如何使用 GrowFromCenter 生動地進入場景。


## TangentLineExample
**說明**: 示範如何在 VMobject 的特定比例位置生成切線。


## SquareToCircle
**說明**: 經典的形狀插值變換，展示 Transform 過程中的預處理技巧。


## BraceAnnotation
**說明**: 在兩點連線上添加動態大括號，並自動生成距離的 LaTeX 標註。


## BooleanOperations
**說明**: 展示圓形與橢圓之間的交集（Intersection）、聯集（Union）與排除（Exclusion）等集合運算。


## VectorArrow
**說明**: 在 NumberPlane 中繪製帶有座標標籤的矢量箭頭，示範 next_to 與 get_end 定位邏輯。


## ManimCELogo
**說明**: 示範如何使用 VGroup 管理複合對象。
