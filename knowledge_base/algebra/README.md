# Algebra Examples

這個資料夾包含 algebra 相關的 Manim 範例代碼。

## 檔案列表


## q
**說明**: 高品質渲染歐拉公式書寫動畫，展示原始字符串 r"..." 的正確用法。


## LinearTransformation
**說明**: 展示 $2 \times 2$ 矩陣如何影響整個二維座標網格，是線性代數視覺化的核心。


## MovingFrame
**說明**: 使用 SurroundingRectangle 框架動態追踪公式中正在被處理的部分。


## EquationSteps
**說明**: 展示代數求解的逐步演進過程，適合作為教學腳本範例。


## MatrixExamples
**說明**: 展示多種括號樣式的矩陣，並利用 get_columns 或 get_rows 高亮特定行列。


## TexTransformExample
**說明**: 演示勾股定理等式的項如何透過 TransformMatchingTex 自動重排。
